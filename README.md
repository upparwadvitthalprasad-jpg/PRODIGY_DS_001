# 🌍 Population Data Visualization using Python

## 📌 Project Overview

This project analyzes and visualizes global population data using Python. The dataset is processed with **Pandas** and visualized using **Matplotlib** and **Seaborn** to understand population trends across countries.

## 📊 Features

- Load and clean World Bank population dataset
- Display Top 10 most populated countries (2024)
- Plot population distribution using histogram
- Visualize India's population growth over time
- Compare countries with populations greater than 100 million

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📂 Dataset

**Dataset Used:**
- `API_SP.POP.TOTL_DS2_EN_csv_v2_327505.csv`

## 📈 Visualizations

- Top 10 Most Populated Countries (Bar Chart)
- Population Distribution (Histogram)
- India Population Growth (Bar Chart)
- Countries with Population Above 100 Million (Bar Chart)
